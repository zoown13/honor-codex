# 개인용 수동 데이터 업데이트

기존 서비스 주소에 `?view=admin`을 붙이고 관리자 암호를 입력합니다.
**데이터 수동 업데이트**에서 예우시설, 혜택 공지, 지자체 조례 중 필요한 원천의 **지금 수집**을 누릅니다.

수집은 백그라운드에서 실행됩니다. 화면을 다시 열어도 최근 작업 상태를 확인할 수 있습니다.
수집 중에는 같은 원천의 중복 요청이 차단됩니다. 실패하거나 20분이 지난 작업은 상태 확인 후 다시 실행할 수 있습니다.
완료되면 검수함을 새로 불러옵니다. 변경사항을 검수·승인한 뒤 기존 게시 기능으로 서비스에 반영합니다.
수동 수집은 AI 정제나 게시를 실행하지 않습니다.

## 배포 순서

1. 기존 파라미터를 유지하여 CDK 스택을 배포합니다. ManualIngestionControl, ManualIngestionWorker 및 GET/POST /v1/pilot-admin/ingestion이 추가됩니다.
2. 백엔드 배포 성공 후 프런트엔드를 Amplify에 배포합니다.
3. 관리자 인증 후 상태 조회, 원천별 수집, 검수함 갱신을 확인합니다.

작업 상태는 기존 DynamoDB 테이블의 MANUAL_INGESTION 파티션에 원천별로 저장합니다.
조건부 쓰기로 중복 실행과 오래된 작업의 상태 덮어쓰기를 차단합니다.
실데이터 수집 허용값과 원천 URL·법제처 설정은 기존 스택 파라미터를 재사용합니다.
기존 정기 수집 설정은 이 변경에서 수정하지 않습니다. 개인용 수동 전용 운영을 원하면 별도로 일정을 비활성화해야 합니다.
