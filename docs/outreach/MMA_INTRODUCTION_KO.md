# 병역명문가 혜택찾기

> 흩어진 예우시설·전국 혜택·지자체 조례를 한눈에 확인하는 오픈소스 파일럿

## 문제 인식

병역명문가를 위한 혜택은 계속 확대되고 있지만, 이용자가 실제 혜택을 찾으려면 예우시설 검색, 전국 혜택 공지, 지자체 조례를 각각 확인해야 합니다. 위치와 이용 조건, 필요한 증빙, 최신 변경 여부도 한 화면에서 비교하기 어렵습니다.

## 제안 서비스

- **내 주변 혜택**: 사용자 위치는 단말에서만 계산하고 가까운 예우시설을 거리순으로 표시
- **통합 조회**: 예우시설, 전국 혜택, 지자체 조례를 모바일 화면에서 통합 검색
- **근거 중심 안내**: 대상, 준비물, 이용 방법, 문의처, 공식 원문과 최종 확인일을 함께 제공
- **변경 추적**: 정기 수집과 검수 흐름으로 신규·수정·종료 항목을 구분

## 현재 파일럿 현황

2026년 8월 5일 게시 데이터셋 기준 총 3,514건을 제공합니다.

- 병무청 예우시설 2,072건
- 전국 혜택 공지 10건
- 지자체 조례 1,432건
- AWS 기반 정적 PWA, 지도, 오프라인 조회, 변경 검수·게시 기능 구현

## 운영 원칙

- 병무청 공식 서비스가 아닌 독립 파일럿이며 공식 원문과 담당부서 안내를 우선합니다.
- AI 정제 내용은 참고용이며 운영자 검수와 공식 원문 확인을 전제로 합니다.
- 정확한 사용자 위치와 자격 증빙 문서를 서버에 저장하지 않습니다.
- 소스 코드와 자체 작성 문서는 Apache License 2.0으로 공개합니다.

## 병무청에 제안드리는 협력 방식

1. 병무청 공식 서비스 내 유사 기능 반영 검토
2. 오픈소스 코드와 AWS CDK 구성의 자유로운 검토·재사용
3. 공식 데이터 연계 또는 자동수집·재사용 조건 협의
4. 필요 시 20~30분 온라인 시연 및 파일럿 결과 공유

현재는 개인 비용으로 소규모 파일럿을 운영하고 있습니다. 대국민 공개 이후에는 데이터 정확성, 보안, 지속적인 갱신과 민원 대응 책임상 개인이 장기간 운영하는 방식보다 기관 주도의 운영이 바람직하다고 생각합니다.
